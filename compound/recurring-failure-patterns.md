# Recurring Failure Patterns

Status: proposed learning artifact

## Patterns

- Handoff visualizations can lag behind canonical protocol changes.
- Important lifecycle stages can exist in older bootstrap docs but disappear from newer diagrams and validators.
- Prompt contracts can be strong while machine enforcement remains weak.
- Optional external collaborator roles can blur into decision authority if not explicitly bounded.
- Research format references can become too domain-specific unless finance, company, market, and global-report formats are required.

## Mitigation

- Keep validator, state machine, startup prompt, and visual overview synchronized.
- Record required/skipped decisions for Deep Interview, KIMI, and Compound Extraction.
- Preserve proposed rules as proposed until operator approval.
