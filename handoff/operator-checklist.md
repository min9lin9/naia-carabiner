# Operator Checklist

Use this checklist before handing the package to another chat or approving more harness changes.

- [ ] Confirm the run classification is acceptable.
- [ ] Confirm KIMI CLI is skipped or explicitly approved.
- [ ] Confirm no real Linear records were written.
- [ ] Confirm no real Paperclip records were written.
- [ ] Confirm canonical file changes are intended.
- [ ] Confirm downstream chat should treat `docs/harness/harness-maker-harness.md` as canonical.
- [ ] Confirm `handoff/startup-prompt.md` is the prompt to use in the next chat.
- [ ] Confirm unresolved open questions are acceptable for handoff.
- [ ] Confirm rollback plan is adequate without git.
